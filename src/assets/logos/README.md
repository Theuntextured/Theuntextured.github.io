# Tool logos

These locally stored assets identify tools used in the portfolio. The original
artwork is retained and displayed on a small white background for contrast in
both website themes.

- `unrealengine.svg`, `cplusplus.svg`, `maya.svg`, `blender.svg`: from
  [Devicon](https://github.com/devicons/devicon/tree/master/icons), MIT license
  included in `DEVICON-LICENSE`.
- `stm32.svg`: from
  [STMicroelectronics' official repository](https://github.com/STMicroelectronics/stm32-util-rot-provisioning/blob/main/doc/subbrand-stm32.svg).
- `solidworks.svg`: from
  [Dashboard Icons](https://github.com/homarr-labs/dashboard-icons/blob/main/svg/solidworks.svg),
  license included in `DASHBOARD-ICONS-LICENSE`.

Brand marks belong to their respective owners. They identify tools, without
implying affiliation or endorsement. The Big Global Challenges title thumbnail
reuses the official badge image already stored in `images/`.

The shared catalog is `src/content/tool-logos.json`. Add logo IDs to an entry's
optional `logos` array to display them beside its title. Entries without a
relevant tool can omit the array.

The Maya certificate uses its own Credly badge image, stored in
`images/autodesk-maya-certificate.png`, from
https://images.credly.com/size/340x340/images/4687d610-d837-4842-8559-02ed2b654993/image.png.
The general 3D modelling entry continues to use the Maya software logo.
